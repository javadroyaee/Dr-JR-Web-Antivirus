# آنتی‌ویروس دکتر JR Web (Dr JR Web Antivirus)

اپلیکیشن امنیتی و آنتی‌ویروس اندروید برای بررسی برنامه‌ها، اسکن فایل‌های حافظه و بهینه‌سازی گوشی.

### دریافت فایل نصبی (APK)
1. وارد تب **Actions** در بالای مخزن گیت‌هاب شوید.
2. روی آخرین بیلد سبز رنگ **Build Dr JR Web APK** کلیک کنید.
3. از بخش **Artifacts** فایل `Dr-JR-Web-Antivirus-APK` را دانلود و نصب نمایید.
